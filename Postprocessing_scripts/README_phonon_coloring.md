# Phonon Dispersion with Element-Projected Colors

This script visualizes phonon dispersion curves with element-projected colors based on atomic contributions to each phonon mode.

## Features

- Reads phonon band structure from `band.yaml` files generated by Phonopy
- Calculates atom-specific contributions to each phonon mode
- Visualizes phonon bands with colors representing the elemental contributions
- Supports two visualization methods:
  1. **Mixed Color Method**: Each segment of the band is colored based on a mixture of element colors weighted by their contributions
  2. **Scatter Method**: Scatter points are plotted with element-specific colors and sizes proportional to their contributions
- Performance optimizations for large files

## Requirements

- Python 3.6+
- NumPy
- Matplotlib
- PyYAML

## Usage

```bash
python plot_phonon_dispersion_color.py [OPTIONS]
```

### Basic Arguments

- `--band`: Path to the band.yaml file (default: band.yaml)
- `--colors`: Path to the VESTA colors file (default: elements-VESTA.ini.txt)
- `--method`: Coloring method to use:
  - `mixed`: Mix RGB values based on elemental contributions (default)
  - `scatter`: Use scatter points with varying sizes and intensities
- `--output`: Output filename for the generated plot (default: phonon_dispersion_colored.png)

### Performance and Debugging Options

- `--max-qpoints`: Maximum number of q-points to process (for testing/debugging)
- `--downsample`: Downsample factor for q-points (e.g., 2 means use every 2nd point)
- `--no-display`: Do not display the plot window (useful for headless environments)
- `--dpi`: DPI for the output figure (default: 300)
- `--figure-size`: Figure size in inches as width,height (default: 10,7)

### Examples

```bash
# Using default parameters
python plot_phonon_dispersion_color.py

# Specify custom files and method
python plot_phonon_dispersion_color.py --band my_bands.yaml --colors my_colors.txt --method scatter --output my_phonon_plot.png

# For large files, use downsampling for faster processing
python plot_phonon_dispersion_color.py --downsample 10 --no-display

# For testing/debugging with a small subset of data
python plot_phonon_dispersion_color.py --max-qpoints 50 --dpi 150
```

## How It Works

1. The script reads the band structure data from the band.yaml file, which contains:
   - Phonon frequencies at each q-point
   - Eigenvectors for each mode (atomic displacements)
   - Atom types and positions

2. For each phonon mode at each q-point, it:
   - Calculates the magnitude of displacement for each atom
   - Normalizes so that the sum of squared magnitudes equals 1
   - Groups and sums the contributions by element type

3. It then visualizes the bands using either:
   - Mixed color method: Linearly combines RGB values from VESTA colors weighted by element contributions
   - Scatter method: Plots scatter points for each element with size and alpha proportional to contribution

4. Elements are identified in the visualization through a legend in the upper right corner showing each element's color.

## Element Colors

The script uses element colors from the VESTA visualization program. The default colors are read from the `elements-VESTA.ini.txt` file, which has the format:

```
Z Element ... R G B
```

where R, G, B are the red, green, blue values (range 0-1) for each element.

## Performance Tips

- For very large band.yaml files (>50MB), consider using `--downsample` or `--max-qpoints` options
- Use `--no-display` in headless environments or when only saving image files
- Reduce `--dpi` for faster rendering and smaller file sizes during testing
- The script attempts to use the faster C-based YAML loader if available
